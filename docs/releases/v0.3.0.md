# MergeLane 0.3.0

This release makes multiple connections explicit, explains why each PR belongs in its lane, and makes automatic cleanup recoverable.

## What's new

- **Saved connections** and a separate **Add connection** action. New forms start blank, with labeled suggestions from open PR tabs.
- **Replace token** renews an existing connection with its owner locked. Stale forms cannot recreate removed connections, and Add cannot overwrite an existing token.
- Connection health shows verified repository access, account-only verification, or a problem needing attention.
- The popup's **PRs** view shows the matching rule beside each PR, including custom labels, any/all rules, and fallback explanations.
- **Recently closed** lists the latest 30 unique PRs closed automatically. **Reopen and keep open** restores a PR without immediately closing it again.
- **Kept open** protections survive browser restarts and apply to every tab for that PR. Grouping continues. **Resume cleanup** explicitly restores automatic closure.
- Keep-open requests take effect even while a slow credential check is pending. Default token checks exclude owners handled by separate connections.

## Install or update

Download **mergelane-0.3.0.zip**, extract it to a permanent folder, and load that folder through **chrome://extensions → Developer mode → Load unpacked**. Existing users can replace files in their current extension folder and click **Reload**. Connections, categories, and pause state are preserved. Chrome 120 or newer is required.

Use the named extension ZIP below; GitHub's source-code archives require building first. No GitHub App or hosted service is required. Organization token approval policies still apply.

## Verification

Unit tests, type checking, the build, and native Chromium integration cover connection routing/import, rule explanations, cleanup protection, command races, recent-history recovery, and a full browser restart. GitHub API and token-page integration tests use fixtures; manual token paste remains available if GitHub changes its page layout.
