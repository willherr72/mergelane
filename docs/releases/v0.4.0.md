# MergeLane 0.4.0

MergeLane now opens your newly created pull requests automatically, then organizes them into the existing workflow lanes.

## What's new

- Checks each explicit owner connection about once a minute for new open PRs authored by the account behind its token. **Refresh now** also checks for new PRs.
- Opens discovered PRs in background tabs without stealing focus, then applies the usual grouping and cleanup rules.
- The first successful scan establishes a baseline without opening older PRs. PRs created while paused are discovered after resuming.
- Existing tabs and loading PR subpages are not duplicated. Manually closed tabs stay closed across worker and browser restarts.
- A failed connection or inaccessible PR does not block other accessible discoveries. GitHub retry windows are respected, and current PR details are checked before opening a tab.
- Pausing during tab creation preserves the record of the created tab, so manually closing it while paused does not cause it to reopen on resume.

Discovery uses existing connections and permissions. Migrated default-token connections continue organizing existing tabs; add an explicit owner connection to discover new PRs for that owner. Removing a connection resets its discovery baseline. Replacing its token preserves history unless the authenticated account changes.

## Install or update

Download **mergelane-0.4.0.zip**, extract it to a permanent folder, and load that folder through **chrome://extensions → Developer mode → Load unpacked**. Existing users can replace files in their current extension folder and click **Reload**. Connections, categories, cleanup protections, and pause state are preserved. Chrome 120 or newer is required.

Use the named extension ZIP below; GitHub's source-code archives require building first. The accompanying `.sha256` file contains the ZIP's checksum.
