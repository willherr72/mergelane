# MergeLane 0.2.0

MergeLane organizes open GitHub pull request tabs into native Chrome groups and closes completed PR tabs after checking their current status.

## Features

- Default lanes: **In Progress**, **In Review**, **Approved**, and **Merging**.
- Human feedback moves PRs into review; author comments and bots are ignored.
- Customize lane names, colors, labels, matching rules, and display order.
- Connect multiple organizations or personal accounts with separate local tokens.
- Assisted token import: open the prefilled GitHub setup from MergeLane, generate a token, and click **Import into MergeLane**. Manual paste is also supported.
- Merged PR tabs close after fresh verification. Unmerged closed PRs receive a one-hour grace period.
- No GitHub App or hosted service required. Organization token policies still apply.

## Install or update

1. Download **mergelane-0.2.0.zip** below and extract it to a permanent folder.
2. Open `chrome://extensions` and enable **Developer mode**.
3. Choose **Load unpacked** and select the extracted folder containing `manifest.json`.
4. Open MergeLane Settings, connect your repository owners, review the cleanup behavior, and enable MergeLane.

If already installed, replace the files in your existing extension folder and click **Reload**. GitHub's automatic source archives are for development; use the named extension ZIP for installation. Chrome 120 or newer is required.

## Validation and limitations

54 unit tests, TypeScript checking, the packaged build, and 20 native Chromium integration checks passed. Automated GitHub tests use fixture responses and pages; assisted import has also been reported working in a user's live setup. If GitHub changes its token-result layout, manual paste remains available.

Tokens stay in trusted local extension storage and are not synced. Local extension storage is not an encrypted vault. The extension is not yet distributed through the Chrome Web Store.
